## Документация:
### Модуль main

### Модуль category:
 Класс Category

Класс описыавет категорию каких то продуктов, у нее есть имя, 
 опесание и список входящих в категорию продуктов. В классе есть две переменные,
 одна отражает сколько всего категорий созданно, вторая сколко продуктов в этих категориях
### Модуль product:
 Класс Product

Класс описыает общеие свойства для любого продукта 
имеет поля: имя, описание, цена и количество
### Модуль utils:
 Функция read_from_json

Функция читает из файла в формате json данные и возвращает в виде списка словарей
 
Функция created_category_with_products

Функция принимает имя json файла в котором указаны категории и соответствующие 
им списки продуктов. На основе этих данных создает объекты категорий с списками продуктов 
и возвращает их в списке.
### Модуль iterator_category:
Класс IteratorCategory

Класс создает возможность итерации по списку продуктов категории
### Модуль lawn_grass:
Класс LawnGrass

Описывает продукт "газонная трава" помимо полей наследуемых от Product
добавлены страна происхождения, период роста и цвет
### Модуль smartphone:
Класс Smartphone

Класс описывает продукт смартфон помимо наследуемых полей добавлены
эффективность, модель, память и цвет
### Модуль base_product:
Класс BaseProduct

Абстрактный класс задающий обязательную функциональность для всех продуктов
 
### Модуль report_by_create_object
Клсс ReportByCreateObject

Класс миксин при создании объектов его наследников выводится строка по 
шаблону: ИмяКласса(значение аргумента1, значение аргумента2, ... значение аргументаN)
